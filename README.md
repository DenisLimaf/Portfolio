---

## 📸 Demonstração das Páginas

O projeto conta com uma navegação dinâmica e páginas temáticas com design moderno e responsivo:

1. **Página Principal (`index.html`)**:
   - Apresentação inicial com cards interativos.
   - Modal com animações suaves e efeito de expansão que direciona o usuário para as páginas detalhadas.
   - *Easter eggs* interativos integrados com Canvas 2D (efeitos Matrix, Hacker e Voo de Avião).

2. **Experiências (`pages/experiencias.html`)**:
   - Linha do tempo com trajetórias formativas (Curso Técnico em Administração, Cursos de Programação e Idiomas).
   - Pilares de atuação e organização.

3. **Habilidades (`pages/habilidades.html`)**:
   - Grid de tecnologias frontend (HTML5, CSS3, JavaScript ES6+, Git/GitHub).
   - Competências em gestão, inglês técnico e soft skills.

4. **Objetivos (`pages/objetivos.html`)**:
   - Metas de inserção profissional (vaga júnior / estágio), projetos freelance e evolução técnica contínua.
   - Botões de conexão e contato.

## 🚀 Tecnologias e Recursos Utilizados

- **HTML5 Semântico**: Estruturação acessível com tags semânticas (`<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, `<footer>`).
- **CSS3 Moderno**: 
  - Flexbox e CSS Grid para layouts totalmente responsivos.
  - Efeitos de profundidade com sombras suaves e micro-interações ao passar o mouse (*hover*).
  - Tipografia moderna utilizando a fonte **Outfit** (Google Fonts).
  - Paleta de cores sofisticada (Dark & Royal Blue).
- **JavaScript Vanilla**:
  - Manipulação dinâmica da DOM para controle de modais.
  - Animações fluidas em HTML5 Canvas 2D via `requestAnimationFrame`.
  - Controle de eventos e navegação modular.

## 💻 Como Executar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/Denilsonstrife/Portfolio.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd Portfolio
   ```

3. Abra o arquivo `index.html` em qualquer navegador ou utilize a extensão **Live Server** no VS Code.
